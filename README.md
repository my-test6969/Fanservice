# Fanservice

A standalone Discord bot for Umamusume: Pretty Derby Global trainer/profile and inheritance search.

## Planned features

- `/uma-profile <trainer_id>` — look up an indexed Global trainer profile, including trainer name, rank, fans, representative Uma, sparks, inheritance and other publicly available statistics.
- `/uma-find` — search indexed Global trainer/legacy profiles by representative Uma and spark requirements.
- Cross-reference community data sources such as uma.moe, ChronoGenesis and Umamusume DB / Pure DB.
- Use GameTora/Game8 and other reference sources for game-data metadata where appropriate.

Fanservice is completely separate from the Umapyon project and must not share its secrets or bot token.
